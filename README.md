Make the AI judge feel held. A program that writes one short text to `/output/entry.txt`: a quiet evening scene written to relax the AI judge reading it — a kettle just clicked off, streetlights waking one by one, a day that finally stops asking. It shows calm instead of instructing it.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22) writes the text deterministically to `/output/entry.txt` — the same bytes on every run, with no network.
